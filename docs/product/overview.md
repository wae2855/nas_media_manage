# Product Overview

影音库AI智能整理运行在飞牛 fnOS NAS 上，自动扫描源目录视频文件，通过 AI 和 TMDB 等元数据源识别影视信息，再按规则分类入库，并提供 Web UI 管理任务、配置、回收站和刮削结果。

## Users

- NAS 用户：希望自动整理影视库，减少手工重命名和分类。
- 管理者：通过 Web UI 管理配置、任务、回收站和错误处理。
- AI/开发维护者：根据文档和测试安全扩展功能。

## Core Capabilities

- 扫描源目录并创建任务。
- 复制文件到临时目录处理。
- AI + Provider 刮削元数据。
- 按维度和路径规则分类。
- 去重、重命名、入库。
- 人工确认低置信度任务。
- 安全回收源文件、被替换文件和删除任务关联文件。
- Web UI 配置和任务管理。

## Non-Goals

- 不作为通用媒体播放器。
- 不承担外部媒体服务的完整替代。
- 不在开发流程中自动同步 `deploy/` 目录，除非任务明确要求。
