# fnOS 首次启动目录授权与多片库用户故事

Requirement: REQ-20260830-180954

## STORY-001 选择多个片库

作为影片分散在多块硬盘的用户，我希望添加多个片库，并给每条整理规则选择目标片库。

验收：可添加、命名、停用多个根；被规则使用的根不能无提示删除；规则目标始终位于所选根内。

## STORY-002 首次启动浏览目录

作为 fnOS 用户，我希望点按钮浏览并授权共享目录，而不是记住并手填路径。

验收：来源、片库和回收都有选择动作；回收选择不允许远程目录；选择器不可用时给出可理解的降级说明。

## STORY-003 旧配置安全升级

作为已有用户，我希望升级后现有入库结果不变，也不必重新配置规则。

验收：单根自动迁移为稳定默认根；旧规则全部绑定该根；无法安全迁移时进入 BLOCKED 而不是猜测。

## STORY-004 可诊断安装

作为安装用户，我希望知道当前等待属于系统 Python 还是应用依赖，并避免应用依赖受网络影响。

验收：项目依赖只从包内安装；日志有阶段与错误；架构不匹配时安装失败关闭。
