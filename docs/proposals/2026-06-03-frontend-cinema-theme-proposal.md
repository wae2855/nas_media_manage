# Frontend Cinema Theme Proposal

## Direction

新前端建议采用“移动优先的私人影院控制台”方向，而不是传统 PC 管理后台。

关键词：

- 黑色底色：接近影院环境，降低灰蒙蒙观感。
- 金色主操作：用于扫描、确认、保存、恢复等关键动作。
- 少量红/绿/青状态色：只服务于失败、成功、进行中，不参与大面积装饰。
- 写实海报墙：顶部用影片海报墙/片库氛围建立影院感。
- 大卡片入口：移动端优先，桌面端只是横向扩展，而不是反过来。
- 首页减负：只显示当前最需要判断和操作的信息。

## Homepage Recommendation

已确认保留：

- 运行状态。
- 当前待处理数量。
- 今日/本轮入库数量。
- 需要人工确认或失败数量。
- 当前正在处理的影片。
- 最近活动。
- 顶部快速动作：立即扫描、暂停、重试失败。
- 3 个首页大入口：任务列表、回收站、系统配置。

移走到子页面：

- 详细系统健康表格。
- 大量路径文字。
- 配置明细。
- 低频诊断信息。
- 长任务列表。
- 独立快速操作面板。

这些内容放入二级工作区或详情页。

## Mobile Structure

移动端底部导航建议固定为 4 个入口：

1. 首页
2. 任务
3. 回收
4. 配置

系统健康、源目录清理和详细配置进入系统配置页；回收站同时保留首页入口卡和底部导航入口。

## Confirmed Decisions

- 首页电影感偏写实海报墙。
- 移动端底部导航固定 4 项：首页、任务、回收、配置。
- 首页不显示系统健康，移动到系统页。
- 最近活动保留在首页当前下方位置。
- 顶部主按钮是立即扫描，旁边按钮是暂停和重试失败。
- 首页中间只保留 3 个大入口：任务列表、回收站、系统配置。
- 首页状态卡点击后进入任务列表，并自动落在对应筛选状态。
- 首页 3 个状态卡固定为横向一排，缩窄时等比收缩，文字居中。
- 系统配置首页改为 4 个横向小卡片：源目录、中转目录、回收目录、入库规则；4 个卡片固定同一行，按四等分宽度随视口联动变化，卡片之间保持紧凑小间距。
- 4 个配置卡右侧显示金色箭头图标，卡片副标题显示有效/无效；该状态最终由系统真实校验返回值驱动，不作为前端硬编码事实。
- 系统配置下部主区域和上部 4 个卡片联动，点击卡片切换对应内容控件。
- 系统配置右上角提供“高级配置”入口，并提供“查看旧版配置”入口用于对照旧前端。
- 源目录主区域去掉承接说明文字，直接展示配置控件。
- 源目录主区域底部追加“源目录智能清理”开关，开启后展开原版“源目录自动清理”核心控件。
- 清理模式和 AI 辅助判断按纵向两行组织，不与其他卡片并排。
- AI 清理提示词展开区域位于 AI 辅助判断下方、合并策略上方；按钮支持点击展开、再次点击收起。
- 合并策略沿用旧版完整选项文案。
- 合并策略按整排展示。
- “执行时间”文案调整为“定时执行”。
- “源目录智能清理”标题附带说明：不选择代表全部清空。
- 源目录标题右侧保留保存按钮，减少来回滚动。
- “源目录路径”采用整行输入布局，并在行末提供“测试权限”；补充源目录说明、共享盘授权提示与网盘刷新建议，并标记为必填项。
- “递归扫描”与“最大扫描深度”合并成一个父卡片，并独占一整行；深度输入随开关启用而显示。
- “中转目录”主区域直接承接旧版核心内容：路径输入整行展示，行末提供“测试权限”，并保留旧版空间建议、SSD 建议和风险提示；路径字段标记为必填项。
- “回收目录”主区域直接承接旧版核心内容：路径输入整行展示，行末提供“测试权限”，保留旧版路径说明和风险提示；“回收站文件保留天数”独占一整行；路径字段标记为必填项。
- “中转目录”“回收目录”主区域标题右侧均补充保存按钮，与源目录操作位置统一。
- “入库规则”主区域改为真实结构承接：规则列表、模板变量说明、兜底入库目录；不保留当前占位预览卡，并为规则列表补充必填标识。
- 入库规则按一条规则一行展示；空状态时以内嵌 `+` 入口承接新增规则，保留“测试所有入库规则目录权限”按钮和原版 fnOS 授权提示。
- 模板变量按分类做成纵向 Disclosure 列表：基础变量、剧集变量、画质变量、AI 维度变量；每类只读展示。
- “兜底入库目录”采用整行输入布局，并保留权限测试入口；注释改为“不设置则匹配不到时按失败处理”。
- 高级配置进入后展示 7 个纵向卡片，卡片不显示数字编号。
- 高级配置大标题下增加轻量路径导航，采用弱化的胶囊式 breadcrumb，而不是厚重的后台路径条。
- “入库名称规范”页改为真实配置表单，展示电影文件名模板、电视剧文件名模板、字幕文件名模板、入库同名文件处理策略；每项独占一行，右上保留保存操作。
- “影视分类维度”页优先承接旧版真实维度控件，而不是重新抽象成摘要卡片。
- “AI刮削提示词”页重组为 3 个 disclosure：LLM纯AI、LLM+TMDB、编写指南；前两者保留恢复默认与完整预览弹窗能力。
- “安全配置”“Hermes通知”“系统设置”页沿用旧版展示方案的字段分组和操作入口，以真实配置表单替代说明卡片。
- 高级配置相关页面从主入口 HTML 中拆出为独立 partial，便于后续继续扩展而不让 `index.html` 失控膨胀。

当前评审结论：系统配置中的基础配置 4 个板块（源目录、中转目录、回收目录、入库规则）已完成本轮展示层收口，可作为后续功能接线和高级配置页继续展开的 UI 基线。

## Configuration IA

系统配置主区域：

1. 源目录：展示并编辑 `source_dir`、扫描递归和深度等基础控件。
2. 中转目录：展示并编辑 `temp_dir`，保留原版说明和权限测试入口。
3. 回收目录：展示并编辑 `source_policy.recycle_dir`、保留天数，并保留原版说明和权限测试入口。
4. 入库规则：承接旧页面 `path_rules`、模板变量说明、`fallback_dir` 等核心内容。

高级配置页：

- 入库名称规范：承接旧页面 `入库设置 / 入库选项`；其中“启用入库前检查”迁到入库规则。
- 影视分类维度：承接旧页面 `入库设置 / 影视分类配置`。
- AI刮削提示词：承接旧页面 `AI刮削 / AI刮削提示词` 折叠区。
- 置信度计算配置：承接旧页面 `AI刮削 / 置信度计算配置`。
- 安全配置：承接旧页面 `通知安全 / API安全配置`。
- Hermes通知：承接旧页面 `通知安全 / Hermes通知`。
- 系统设置：承接旧页面 `通知安全 / 高级配置`。
