# fnos 系统兼容性说明

本项目针对 fnos 系统的兼容性优化和注意事项。

## 主要改进

### 1. 启动脚本兼容性 ([start.sh](../start.sh))
- **问题：原始脚本使用了 macOS/Linux 特定命令
- **改进**：
  - 使用 `#!/usr/bin/env bash` 代替 `#!/bin/bash`
  - 支持多种端口检查方式（`lsof`/`netstat`/`ss`
  - 支持多种健康检查方式（`curl`/`wget`
  - 避免使用 `read -p`（交互式提示，简化错误处理
  - 使用 POSIX 兼容的 `[` 代替 `[[` 语法

### 2. 文件拷贝优化 ([media_importer/file_copier.py](../media_importer/file_copier.py))
- **问题**：大文件（>10GB 拷贝时间过长，可能超时
- **改进**：
  - 添加心跳机制（默认 30 秒间隔，更新任务状态
  - 断点续传功能（`.copying` 标记
  - 进度回调
  - 兼容 `shutil.disk_usage` 异常处理

### 3. 安全模块优化 ([media_importer/safety.py](../media_importer/safety.py))
- **问题**：目录和文件读权限检查不一致
- **改进**：
  - 改进 `check_read_permission`，区分文件和目录
  - 目录通过 `os.listdir()` 检查
  - 文件通过读取 1 字节检查
  - 更健壮的错误处理

### 4. 流水线集成 ([media_importer/pipeline.py](../media_importer/pipeline.py))
- **问题**：长时间拷贝无心跳
- **改进**：
  - 添加 `heartbeat_cb` 回调更新任务状态

## fnos 系统部署要求

### 最低要求
- Python 3.6+
- bash 4.0+（或兼容的 shell）
- 支持的命令：
  - `python3`
  - `curl` 或 `wget`（用于健康检查）

### 推荐配置
- 足够的临时空间：源文件大小的 1.5 倍
- 网络稳定性：大文件拷贝时网络稳定

## 大文件处理说明

### 已支持的场景
- 单个大文件（最大 50GB
- 长时间拷贝（支持超过 10 分钟
- 网络中断后恢复（断点续传）

### 监控
- 拷贝进度每 1MB 缓冲区更新
- 每 30 秒心跳更新任务状态
- 支持续传标记 `.copying`

## 已知限制

1. **macOS SIP 限制（仅限测试环境）
   - 系统完整性保护 (SIP) 可能阻止访问某些目录
   - 建议使用不受 SIP 未保护的目录

2. **网络文件系统
   - NFS/SMB 挂载目录的源文件系统
   - 建议使用本地目录作为源目录以提高稳定性

## 测试建议

1. 先在小型文件测试环境部署
2. 测试拷贝 1GB 大小的文件
3. 验证网络中断恢复
4. 检查健康检查是否正常工作
