# 前端页面文案与行为同步方案

## 目标

将 UI 从历史「AI 刮削 + 三级匹配 + 联网搜索 + Hermes」叙述同步到当前事实：

```text
文件名规则清洗 → TMDB Provider 两级匹配 → AUTO_PASS 或 NEEDS_CONFIRM
LLM 仅用于源目录清理建议，不参与刮削、维度判断或联网搜索。
```

此次不是纯文案替换。凡是过时文案仍驱动旧 UI 状态、模拟器解释或操作范围的，必须同步收敛行为，防止“页面说对了，操作仍按旧规则做”。

## 当前审计结果

### P2：操作语义与现行状态机不一致

| 文件 | 当前问题 | 调整 |
|---|---|---|
| `cinema-task-batch.js` | 批量重试文案与筛选包含 FAILED/SKIPPED/CANCELLED，后端 `retry_all_failed` 已收敛为仅 FAILED | 批量入口只选择 FAILED；文案改为“批量重试失败任务”；单任务重试维持现有显式复活能力时需明确提示 |

## 文案原则

1. **事实优先**：只描述已实现行为。TMDB 为当前唯一 Provider，不写“豆瓣等”“多 Provider 顺序”。
2. **主链路与可选能力分开**：Provider 是刮削必需；LLM 是清理器可选；hooks 是高级扩展。
3. **不承诺不可控结果**：不说“AI 提高命中率”“完整工作”；明确 NEEDS_CONFIRM 是可靠兜底而非失败。
4. **状态机术语统一**：排队中、处理中、需要确认、成功入库、失败、已跳过、已取消；重试说明 checkpoint 续跑语义。
5. **历史数据兼容**：旧任务的 AI 来源可显示“历史来源”，但不得伪装为当前行为。

## 实施批次

### 批 A：主流程与引导（P0）

- 重写首页首次使用、进阶建议、刮削流程卡。
- 删除联网搜索卡。
- 重写模拟器静态说明和动态等级/时间线/维度来源渲染。
- 更新限制级维度说明。

验收：搜索 `三级匹配|AI辅助匹配|AI搜索|联网搜索|AI 判定` 在活跃 UI 中为 0（仅历史数据兼容映射注释可保留）；运行模拟页面展示两级路径。

### 批 B：配置与高级页面（P1）

- 收缩源目录清理器 AI 文案，删除已不存在提示词配置入口。
- 重写高级配置、元数据配置和维度页说明。
- 清理已失效 CSS 注释和死的 AI demo 样式。

验收：从任意页面不会导航到不存在的 AI 提示词、场景策略、联网搜索或通知配置。

### 批 C：任务操作与历史兼容（P2）

- 批量重试仅 FAILED，复制后端 S3 语义。
- 更新单任务重试、失败提示、断点续跑说明。
- 对旧 `ai_*` 来源标签统一标记“历史来源”，新数据只使用当前来源集。

验收：批量选择、确认文案、API 实际参数三者一致；任务详情对新旧数据均无误导文案。

### 批 D：验证与防漂移

- Playwright：首次配置、LLM 卡、模拟器、维度编辑、任务详情、批量重试、回收页六页冒烟。
- 静态文案扫描脚本加入已退役词规则（三级匹配、AI 辅助匹配、联网搜索、Hermes 等）。
- `docs/product/frontend-information-architecture.md` 和 `docs/features/scraping.md` 更新当前用户术语。

## 非目标

- 不改变 TMDB 匹配算法、状态机规则、Provider API 或文件操作策略。
- 不新增语言、主题、i18n 框架。
- 不重做视觉设计；仅清理已死样式，并保持当前 cinema 视觉语言。
