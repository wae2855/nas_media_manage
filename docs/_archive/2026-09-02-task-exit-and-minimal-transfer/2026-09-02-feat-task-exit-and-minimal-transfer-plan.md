# 任务安全退出、来源处置与最少大文件传输实施计划

- **Requirement**: [REQ-20260902-021000](../../tracking/requirements-board.md)
- **Proposal**: [任务退出、来源处置与最少传输方案](../../proposals/2026-09-02-task-exit-and-minimal-transfer.md)
- **ADR**: [ADR-0021](../../decisions/0021-task-exit-and-direct-library-staging.md)

## 验收标准

- 排队、运行、待确认、重复、失败、跳过、取消、成功和重新整理均有明确、合法、普通人可理解的退出动作。
- 运行中停止在安全检查点生效；目标视频提交后拒绝取消。
- 保留片库现有文件时可独立选择保留或回收新资源，片库文件哈希不变。
- 删除记录不触碰任何文件；来源处理失败不删除记录。
- 单任务回收只包含登记的视频和字幕，不递归删除同目录其他内容。
- 新任务确认前无大文件复制；确认后默认直接进入目标暂存，旧中转断点继续复用。
- 桌面和 390/360/320px 前端流程无横向溢出，批量混合状态显示逐项结果。
- 本地真实目录和文件在前端完成全矩阵验收，包含大文件进度、停止、重复保留、回收、记录删除和片库哈希保护。

## 实施任务

- [x] 1. 数据与状态合同
  - 增加停止请求、待执行来源动作、用户结果和来源处置结果字段及旧库迁移。
  - 冻结每个状态允许的动作、HTTP 结果和终态文案。

- [x] 2. 状态感知处置服务
  - 实现保留来源、本地回收、受控永久删除和只删记录。
  - 运行中只登记停止请求；非运行态同步完成。
  - 片库路径、重新整理任务和来源单元多任务边界失败关闭。

- [x] 3. 协作式安全停止
  - runner/confirm 在步骤边界、复制、哈希和发布回调检查请求。
  - 提交前回退任务暂存并清理专属临时内容；提交后继续完成。
  - 重启时恢复尚未完成的停止请求。

- [x] 4. 最少传输规划
  - 新任务跳过来源到本地中转，直接写目标任务暂存。
  - 目标暂存复制复用 SHA-256、fsync、断点和 bundle journal；避免复制前额外完整哈希读取。
  - 旧中转断点继续从 temp 入库，不重复读取来源。

- [x] 5. 冲突和普通任务 UI
  - 卡片/详情用“结束处理”“删除记录”替换误导动作。
  - 增加来源去向弹窗和“正在安全停止”反馈。
  - 冲突卡提供保留片库+保留/回收新资源；永久删除仅在已启用时显示。
  - 批量操作按状态分组、逐项汇总并适配移动端。

- [x] 6. 自动化与真实前端验收
  - 状态矩阵、并发、重启、目标提交点、来源多任务和片库保护测试。
  - 真实目录生成来源/中转/回收/多个片库及字幕场景。
  - 通过本地服务和 Chromium 从任务列表逐项点击完成桌面与移动端流程。
  - 运行 lint、编译、架构护栏、相关回归和文档检查；记录 PASS/FAIL/NOT_RUN。

## 完成证据

- `python3 -m pytest tests/`：`1019 passed`，包含真实本地 HTTP 服务与 Chromium 前台流程。
- 客户视角逐项点击：排队保留、待确认回收、运行中安全停止、重复片保留片库并回收新资源、失败后保留、完成记录删除均通过。
- 片库保护：重复片和删除记录场景均逐字节复核目标片库测试文件未改变；单任务回收只移动登记的视频和字幕，同目录无关文件保留。
- 最少传输：识别、规则、目标和重复冲突确认前不复制大文件；新任务确认后来源直接写目标侧任务暂存，旧中转断点仍可继续。
- 替换来源策略：确认替换时新来源先复制到目标暂存，发布后仍由统一的保留/回收/永久删除策略收尾，不再被替换分支隐式删除。
- 移动端：390px 真实 Chromium 弹窗无页面或弹窗横向溢出；页面错误和 HTTP 5xx 均为 0。
- Ruff、Python compileall、JavaScript 语法、架构护栏及文档检查均通过。
- fnOS 真机验收：`NOT_RUN`，本轮只完成本地开发环境与浏览器验收。
