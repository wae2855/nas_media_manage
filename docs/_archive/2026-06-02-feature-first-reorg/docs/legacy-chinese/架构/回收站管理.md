# 回收站管理模块

**对应源码路径**

| 模块 | 路径 |
|------|------|
| 回收站管理器 | `media_importer/core/recycle/manager.py` |
| 回收站浏览器 | `media_importer/core/recycle/browser.py` |

> 从 `core/safety.py` 拆分而来，原安全工具模块仅保留路径校验和安全操作功能。文件操作相关文档见 [文件操作](文件操作.md)。

---

## 概述

回收站是系统唯一的安全出口，所有需要移除的文件都先进入回收站，不直接删除。回收站模块负责文件的移入、浏览、恢复、永久删除和过期清理，按来源区域分区管理，并通过 `.meta`/`.dir.meta` 侧车文件记录来源信息以支持恢复。

---

## 目录结构

```
{recycle_dir}/
└── {YYYY-MM-DD}/
    ├── [源目录]/            # 来自源目录的文件（任务流清理、忽略操作）
    ├── [入库目录]/          # 来自入库目录的文件（去重替换、任务删除）
    ├── [清理器-源目录]/     # 清理器从源目录清理的文件
    └── [其他]/              # 无法归类的文件
```

---

## 元信息文件

每个回收站文件/目录旁都有 `.meta`/`.dir.meta` 侧车文件：

```json
{
    "original_path": "/vol1/.../电影.mkv",
    "source_zone": "source",
    "reason": "source_cleanup",
    "task_id": "T20260529-001",
    "moved_at": "2026-05-29T10:30:00",
    "file_size_mb": 20.5
}
```

---

## reason 值标准化

| reason 值 | 来源 | 说明 |
|-----------|------|------|
| `source_cleanup` | 任务流 | 任务完成后源文件清理 |
| `task_delete` | API | 用户删除任务 |
| `dedup_replace` | 任务流 | 去重替换旧文件 |
| `quality_replace` | 任务流 | 质量替换旧文件 |
| `import_overwrite` | 入库 | 入库目录同名覆盖 |
| `source_cleaner:non_media` | 清理器 | 非媒体文件 |
| `source_cleaner:delete_extension` | 清理器 | 匹配删除后缀 |
| `source_cleaner:junk_video` | 清理器 | 垃圾视频 |
| `source_cleaner:blacklist_pattern` | 清理器 | 黑名单匹配 |
| `source_cleaner:ai_delete` | 清理器 | AI 判定删除 |
| `source_cleaner:empty_dir` | 清理器 | 空目录 |
| `source_cleaner:blacklist_dir` | 清理器 | 黑名单目录 |

## 核心函数

### 回收站管理器（manager.py）

| 函数 | 用途 | 安全检查 |
|------|------|---------|
| `move_to_recycle` | 文件移入回收站 | 路径校验 + 来源区域分区 + .meta 侧车文件 |
| `move_to_recycle_with_companions` | 源文件+附属文件移入回收站 | 同 move_to_recycle + 伴随文件查找 |
| `move_dir_to_recycle` | 目录整体移入回收站 | 路径校验 + .dir.meta 侧车文件 |
| `recycle_cleanup` | 回收站过期清理 | 兼容 .meta 和 .dir.meta |

### 回收站浏览器（browser.py）

| 函数 | 用途 |
|------|------|
| `list_recycle_dir` | 浏览回收站，返回文件列表+分区统计+是否可恢复 |
| `restore_from_recycle` | 恢复文件/目录到原位置，冲突处理（skip/overwrite/rename） |
| `delete_from_recycle` | 永久删除回收站文件/目录 |

---

## 文件删除规则

| 文件类型 | 删除方式 | 说明 |
|---------|---------|------|
| 临时文件（.tmp/.copying） | 直接 rm 删除 | 临时文件是工作副本，不入回收站 |
| 中转目录文件（temp） | 直接 rm 删除 | 处理完成/失败后清理，不入回收站 |
| 源文件（完成状态） | move_to_recycle 移入回收站 | cleanup_source_after_done=true 时 |
| 源文件（完成状态） | 保留不动 | cleanup_source_after_done=false 时 |
| 源文件（FAILED 状态） | 保留在源目录 | 等用户决策，不自动移入回收站 |
| 入库去重替换的旧文件 | move_to_recycle 移入回收站 | 高清替换场景 |
| 删除任务关联文件 | move_to_recycle 移入回收站 | 用户选择删除时 |

---

## 回收站业务流

```
文件删除/覆盖请求 → move_to_recycle() → 日期子目录 + 来源区域分离
  → .meta 侧车文件记录来源信息 → 文件可恢复

回收站浏览 → list_recycle_dir() → 解析 .meta/.dir.meta → 返回文件列表+分区统计
回收站恢复 → restore_from_recycle() → 读取 .meta 获取原位置 → 移回原位置（冲突处理）
回收站永久删除 → delete_from_recycle() → 直接删除文件/目录+元信息
```

---

## 职责边界

### 负责

- 文件移入回收站（move_to_recycle / move_to_recycle_with_companions / move_dir_to_recycle）
- 回收站浏览（list_recycle_dir）
- 回收站恢复（restore_from_recycle）
- 回收站永久删除（delete_from_recycle）
- 回收站过期清理（recycle_cleanup）

### 不负责

- 路径安全校验（由 `core/safety.py` 执行）
- 安全删除/移动操作（由 `core/safety.py` 执行）
- 任务状态管理（由 TaskManager 执行）
- 源目录清理判定逻辑（由 SourceCleaner 执行）

## 配置项说明

| 键 | 类型 | 默认值 | 说明 |
|----|------|--------|------|
| `recycle_dir` | string | - | 回收站目录路径（source_policy 配置） |
| `recycle_retention_days` | int | 30 | 回收站保留天数（0=永不过期） |
