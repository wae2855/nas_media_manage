# 影音库AI智能整理 UI/UX 改进方案

> 基于 Playwright 截图深度分析 + 用户心理学 + 渐进式披露原则

---

## 一、当前界面现状评估

### 1.1 整体视觉风格

| 维度 | 当前状态 | 评分 |
|------|---------|------|
| **色彩方案** | 深色主题 + 蓝色主色调 (#3B82F6)，专业感尚可 | ⭐⭐⭐ |
| **字体层级** | 系统默认字体，层级区分不够明显 | ⭐⭐ |
| **间距节奏** | 统一但略显紧凑，缺乏呼吸感 | ⭐⭐⭐ |
| **圆角一致性** | 8px-12px 圆角，基本一致 | ⭐⭐⭐⭐ |
| **阴影与层次** | 卡片有悬浮效果，但整体扁平 | ⭐⭐⭐ |
| **动效过渡** | 有基础 transition，但缺乏微交互 | ⭐⭐ |

**总体视觉印象**：功能完整、风格统一，但**缺乏设计感与品牌辨识度**，像是一个"能用的后台管理面板"而非"精心设计的产品"。

### 1.3 各页面详细评估

#### 📊 概览页面（首页）

**优点：**
- ✅ 四宫格统计卡片直观展示核心指标
- ✅ 卡片可点击跳转，交互合理
- ✅ 健康状态一目了然

**问题：**
- ❌ **信息过载**：一次性展示 5 个区块（统计卡片 + 流程图 + 运行状态 + 快捷操作 + 安全提示），新用户会感到压力
- ❌ **流程图默认折叠是正确的**，但标题不够吸引人去展开
- ❌ **安全提示框**位置突兀，且始终显示 API Key 错误 toast，造成视觉干扰
- ❌ **快捷操作按钮**没有明确的主次关系，4 个按钮看起来一样重要
- ❌ 缺少 **"下一步该做什么"** 的引导

#### ⚙️ 配置页面（核心问题最集中）

**优点：**
- ✅ 子页签分类逻辑清晰
- ✅ 表单控件类型丰富（输入框、下拉、开关、多选等）
- ✅ 有帮助提示文字

**问题（严重）：**
- ❌ **7 个子页签 + 1 个动作按钮 = 导航认知负荷过高**
- ❌ **所有配置项平铺展示**，没有"常用/高级"的区分
- ❌ **每个子页签内容都很多**，用户需要大量滚动
- ❌ **缺少配置向导**：新用户不知道应该从哪里开始配置
- ❌ **"影视分类配置"和"入库设置"应该是第一步**，但没有突出显示
- ❌ **表单标签描述偏技术化**（如"递归扫描源目录"、"最大递归深度"）
- ❌ **警告提示过多**（黄色提示框密集出现），导致"警告疲劳"
- ❌ **保存按钮在底部 sticky bar**，长页面时体验好，但用户可能不知道需要保存

#### 📋 任务页面

**优点：**
- ✅ 状态筛选 tab 清晰
- ✅ 表格列信息完整
- ✅ 实时日志区域实用

**问题：**
- ❌ **空状态时只显示错误信息**，没有友好的引导
- ❌ **日志区域默认空白**，缺少示例或说明
- ❌ **表格没有搜索/排序功能**

#### 🗑️ 回收站页面

**优点：**
- ✅ 统计卡片清晰
- ✅ 筛选器完整
- ✅ 批量操作可用

**问题：**
- ❌ 同样受 API Key 错误 toast 干扰
- ❌ 空状态可以更友好

## 二、用户心理学分析

### 2.1 新用户首次使用心理模型

```
用户打开系统后的内心独白：
"这是什么？我能用它做什么？我该怎么开始？"
                    ↓
        【困惑期】需要明确的引导
                    ↓
"哦，这是一个自动整理影视文件的工具"
                    ↓
        【理解期】需要快速上手的最小路径
                    ↓
"那我需要先配置什么？这里有好多选项..."
                    ↓
        【决策焦虑期】需要渐进式披露
```

### 2.2 认知负荷理论应用

| 设计原则 | 当前状态 | 改进方向 |
|---------|---------|---------|
| **希克定律**（选择越多反应越慢） | 7个配置子页签同时可见 | 减少到 3-4 个核心入口 |
| **米勒定律**（工作记忆 7±2） | 首页 5 大区块同时展示 | 分优先级，默认折叠次要内容 |
| **菲茨定律**（目标越大越易点击） | 操作按钮大小一致 | 主要操作按钮加大加粗 |
| **格式塔原则**（相近相关） | 相关配置分散在不同页签 | 按使用场景重新分组 |
| **雅各布定律**（用户习惯其他产品） | 自定义的导航结构 | 采用行业通用的 Dashboard 模式 |

### 2.3 用户角色与场景

| 角色 | 使用频率 | 核心需求 | 当前痛点 |
|-----|---------|---------|---------|
| **新手用户** | 首次使用 | 快速配置并跑通第一个任务 | 不知道从哪开始，被大量配置吓退 |
| **日常用户** | 每周查看 | 确认任务状态，处理异常 | 需要翻多个页签才能看到关键信息 |
| **高级用户** | 偶尔调优 | 调整参数、排查问题 | 高级选项和基础选项混在一起 |

#### 关键改动说明

| 改动点 | 原因 | 用户心理学依据 |
|-------|------|---------------|

| **三大行动入口** | 给用户明确的第一步选择 | 选择架构 - 减少决策困难 |
| **最近活动流** | 展示系统在工作，建立信任感 | 社会证明 - 别人/系统在使用 |
| **次要内容折叠** | 降低初始认知负荷 | 渐进式披露 |
| **移除右下角常驻 Toast** | 消除持续视觉干扰 | 注意力经济 |

#### 配置项分级策略

| 级别 | 显示方式 | 包含内容 | 示例 |
|------|---------|---------|------|
| **P0 - 必须配置** | 默认展开，红色星标 | 源/中转/回收站目录 | `source_dir`, `temp_dir` |
| **P1 - 推荐配置** | 默认展开，无特殊标记 | AI Provider, 入库规则 | `llm.api_key`, `path_rules` |
| **P2 - 常用可选** | 折叠区块标题可见 | 文件清理策略, 通知 | `cleanup_mode`, `hermes` |
| **P3 - 高级/罕见** | "高级设置"折叠区内 | 置信度参数, 轮询间隔 | `confidence.*`, `watcher.*` |

### 3.4 方案三：视觉升级 —— 从"能用"到"好用好看"

#### 3.4.1 色彩体系优化

```css
/* 当前 */
--primary-color: #3B82F6;  /* 通用蓝 */

/* 建议 - 更有质感的渐变色系 */
--primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
--primary-solid: #6366f1;
--primary-light: rgba(99, 102, 241, 0.1);
--accent-cyan: #06b6d4;
--accent-emerald: #10b981;
--accent-amber: #f59e0b;
--accent-rose: #f43f5e;
```

#### 3.4.2 卡片组件升级

```
当前卡片:
┌─────────────────────────┐
│ [图标]  0               │
│         待处理（当前队列）│
└─────────────────────────┘

升级后卡片:
┌─────────────────────────────────┐
│ ╭─────────────────────────────╮ │
│ │  ⏱️                         │ │
│ │       0                     │ │
│ │   待处理任务                 │ │
│ │                             │ │
│ │   点击查看详情 →             │ │
│ ╰─────────────────────────────╯ │

│     ↑ 5% 较昨日               │ │
└─────────────────────────────────┘
```

**改进要点：**
- 增加**趋势指示器**（上升/下降箭头 + 百分比）
- 增加**微妙的顶部渐变边框**表示卡片类型
- 增加**行动召唤文案**（"点击查看详情"）

#### 3.4.3 表单控件优化

| 控件类型 | 当前 | 升级 |
|---------|------|------|
| **输入框** | 普通 border | focus 时左侧彩色边框 + 浮动 label |
| **开关** | 圆形 toggle | 带 on/off 文字的大号开关 |
| **下拉框** | 原生 select | 自定义下拉带图标和描述 |
| **按钮组** | 平铺 | 主按钮渐变 + 次按钮描边 |

#### 3.4.4 微交互动效

```css
/* 卡片悬浮 */
.card:hover {
    transform: translateY(-4px);
    box-shadow: 0 20px 40px rgba(0,0,0,0.3);
}

/* 页面切换 */
.panel { animation: fadeSlideIn 0.3s ease-out; }
@keyframes fadeSlideIn {
    from { opacity: 0; transform: translateY(10px); }
    to { opacity: 1; transform: translateY(0); }
}

/* 数字变化 */
.card-value { transition: all 0.5s cubic-bezier(0.34, 1.56, 0.64, 1); }

/* 成功反馈 */
.btn-success:active {
    transform: scale(0.95);
}
```

## 六、总结与建议

### 核心改进理念

```
Before: "功能完整的后台管理系统"
After:  "让用户 30 秒上手的智能影视管家"
```

### 最关键的 3 个改动

1. **首页改造** - 从"监控面板"变成"产品首页"，给用户明确的行动指引
2. **配置分级** - 将 7 个配置页签压缩为 3 个分组 + 折叠高级选项
3. **消除干扰** - 移除常驻错误提示，优化空状态文案

### 不改动的部分

- ✅ 深色主题（NAS 环境合适）
- ✅ 基本的 Tab 导航结构（只需简化）
- ✅ 后端 API 和数据结构（纯前端改动）
- ✅ 核心功能逻辑（不改业务逻辑）
