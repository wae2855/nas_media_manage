## 概述

文件操作模块负责 影音库AI智能整理中所有文件 I/O 操作，涵盖从源目录扫描到最终入库的完整文件流转链路。模块按职责拆分为 7 个子模块 + 1 个安全基础设施模块，流水线调用顺序为：

```
scan → copy → scrape → validate → classify → dedup → rename → import → notify → record
  │      │                                    │        │        │
  │      │                                    │        │        └─ file_mover (move_to_import)
  │      │                                    │        └────────── dedup_checker (check_duplicate)
  │      │                                    └─────────────────── classifier (classify)
  │      └── file_copier (copy_to_temp)
  └── file_scanner (scan_and_filter)
```

## 文件扫描器

**类**: `FileScanner`

### 职责

扫描源目录，识别视频与字幕文件，按名称分组关联，过滤已处理文件。

### 支持的文件扩展名

| 类型 | 扩展名 |
|------|--------|
| 视频 | `.mp4` `.mkv` `.avi` `.mov` `.wmv` `.flv` `.webm` `.m4v` `.m2ts` `.ts` `.iso` `.bdmv` |
| 字幕 | `.srt` `.ass` `.ssa` `.sub` `.idx` `.smi` |

### 核心流程

```
scan_and_filter(source_dir)
│
├─ scan_path(directory)
│   ├─ os.walk 遍历，跳过隐藏目录（.开头）
│   └─ _group_videos(all_files)
│       ├─ 按扩展名分离 video_set / subtitle_set
│       ├─ _clean_name 清洗文件名（去标签词、统一分隔符）
│       ├─ 第一轮匹配：clean_name 匹配字幕文件名
│       └─ 第二轮匹配：同目录 + basename 匹配剩余字幕
│
└─ 过滤已处理文件
    ├─ task_manager.check_source_duplicate(video_path)
    ├─ action == "SKIP" → 更新 last_seen_at，跳过
    └─ 否则 → 保留
```

### _clean_name 清洗规则

1. 去除尾部扩展名
2. 去除质量标签：`1080p/720p/2160p/4k/bluray/web-dl/hdtv/x264/x265/hevc/aac/dd5.1/ac3`
3. 统一分隔符 `.` `_` `-` `空格` → 单空格
4. 转小写

### 输出结构

```json
{
  "video_path": "/source/movie.mkv",
  "video_file": "movie.mkv",
  "video_dir": "/source",
  "file_size_mb": 1234.5678,
  "subtitle_files": ["/source/movie.zh.srt"]
}
```

### 排序

| sort_by 值 | 排序键 | sort_reverse |
|------------|--------|-------------|
| `filename` | video_file | 默认 False |
| `size` | file_size_mb | 默认 False |

### 便捷函数

`scan_source_dir(source_dir, config, task_manager)` → 一行调用入口

## 文件复制器

**类**: `FileCopier`

### 职责

将源文件复制到中转目录，支持断点续传、进度回调和心跳。

### 初始化

```python
FileCopier(temp_dir)
```

- 自动创建 `temp_dir`，失败则 `_available = False`
- 不可用时所有操作将抛出异常

### 核心流程

```
copy_to_temp(video_path, subtitle_paths, progress_callback, heartbeat_callback)
│
├─ check_write_permission(temp_dir)
├─ copy_file_with_marker(video_path, dest_video)
│   ├─ check_read_permission(src)
│   ├─ validate_file_ext(src, ALLOWED_MEDIA_EXTS)
│   ├─ check_disk_space(file_size)  → 需要 1.5x 空间
│   ├─ 检测 .copying 断点文件 → 有则续传(ab)，无则新建(wb)
│   ├─ 1MB 块读写循环
│   │   ├─ progress_callback(copied_bytes, total_bytes)
│   │   └─ heartbeat_callback()  → 每 heartbeat_interval 秒
│   └─ os.rename(.copying → dest)
│
└─ 逐个 copy_file_with_marker(subtitle_path, dest_sub)
```

### 断点续传机制

| 状态 | 文件 | 行为 |
|------|------|------|
| 复制中 | `filename.copying` | 追加写入 (`ab` 模式) |
| 完成 | `filename` | `os.rename` 原子重命名 |
| 残留 | `filename.copying` | `cleanup_residual_copies()` 清理 |

### 磁盘空间检查

`check_disk_space(file_size)` → `disk.free >= file_size * 1.5`

## 文件搬运器

**模块函数**（无类，纯函数式）

### 函数清单

| 函数 | 用途 |
|------|------|
| `move_to_import` | 视频+字幕移动到入库目录，应用文件名模板 |
| `apply_filename_template` | 渲染文件名模板 |
| `apply_subtitle_template` | 生成字幕文件名：`{video_name}.{lang}{ext}` |
| `detect_subtitle_lang` | 从文件名检测字幕语言 |
| `delete_source_files` | 安全删除源文件列表 |
| `find_companion_files` | 查找视频的伴随文件（NFO、图片等） |
| `delete_source_with_companions` | 删除源文件 + 伴随文件 |
| `cleanup_source_non_media` | 清理源目录中的非媒体文件和空目录 |
| `remove_empty_parent_dir` | 递归删除文件移走后的空父目录 |
| `move_with_cross_device_fallback` | 跨设备移动（封装 safe_move） |

### move_to_import 流程

```
move_to_import(video_path, subtitle_paths, import_dir, scraped_info,
               filename_templates, allowed_base_dirs, overwrite)
│
├─ check_write_permission(import_dir)
├─ validate_path_safety(import_dir, allowed_base_dirs)
├─ os.makedirs(import_dir)
│
├─ 选择模板
│   ├─ type == 'tv'  → filename_templates['tv']
│   └─ type == 'movie' → filename_templates['movie']
│
├─ apply_filename_template → final_video_filename
├─ 目标同名检查
│   ├─ overwrite=True → os.remove(dest)
│   └─ overwrite=False → raise IOError
│
├─ safe_move(video_path, dest_video)
│
└─ 逐个处理字幕
    ├─ detect_subtitle_lang(sub_filename) → lang
    ├─ apply_subtitle_template → final_sub_filename
    └─ safe_move(sub_path, dest_sub)
```

### 字幕语言检测规则

| 文件名模式 | 语言代码 |
|-----------|---------|
| `.zh.` `.chs.` `chinese` | `zh` |
| `.en.` `.eng.` `english` | `en` |
| `.ja.` `.jpn.` `japanese` | `ja` |
| `.ko.` `.kor.` `korean` | `ko` |
| 其他 | `unknown` |

### 伴随文件查找逻辑

`find_companion_files`：扫描视频同目录，查找以视频 basename 开头、但非视频/字幕扩展名且非已知文件的文件（如 NFO、海报图等）。

### 源目录清理

```
cleanup_source_non_media(source_dir, video_extensions, subtitle_extensions)
│
├─ os.walk(topdown=False)  → 自底向上
├─ 删除非媒体扩展名的文件
├─ 删除空子目录（不删 source_dir 本身）
└─ return (deleted_files, deleted_dirs)
```

## 文件分析器

**模块函数**（无类）

### 职责

通过 ffprobe 检测视频文件的技术参数，当前仅支持分辨率检测。

### 可用性检查

`check_ffprobe_available()` → 首次调用 `shutil.which("ffprobe")`，结果缓存到 `_ffprobe_available`

### 分辨率检测

```
detect_resolution(video_path)
│
├─ ffprobe -v quiet -print_format json -show_streams -select_streams v:0
├─ 解析 JSON → streams[0].width / height
├─ 超时 30s
└─ 失败返回 {"width": 0, "height": 0}
```

### 分辨率分级

`classify_resolution_tier(width, value_list)`

- `value_list` 来自维度配置，每项含 `value`（分级名）和 `min_width`（最小宽度）
- 按 `min_width` 降序匹配，首个 `width >= min_width` 命中
- 无匹配时回退到 `sd`
- 特殊：`value == "sd"` 的项不参与排序匹配，仅作兜底

### analyze_file 输出结构

```json
{
  "resolution_tier": {
    "value": "1080p",
    "confidence": 1.0,
    "source": "file",
    "detail": "1920x1080"
  }
}
```

| 字段 | 说明 |
|------|------|
| `value` | 分级结果 |
| `confidence` | 固定 1.0（文件分析确定性高） |
| `source` | 固定 `"file"` |
| `detail` | 原始分辨率字符串 |

## 去重检查器

**模块函数**（无类）

### 职责

在入库目录中检测同名/同内容文件，根据策略决定处理方式。

### 核心流程

```
check_duplicate(import_path, scraped_info, strategy, new_file_path)
│
├─ find_existing_file(import_path, scraped_info)
│   ├─ os.walk 遍历入库目录
│   ├─ 逐文件 parse_filename_info → 提取 title_cn/en/year/season/episode
│   ├─ 匹配条件：year 匹配 AND title 匹配 AND season 匹配 AND episode 匹配
│   └─ 返回匹配文件列表
│
└─ 按策略生成结果
    ├─ skip      → is_duplicate=True, action=skip
    ├─ replace   → is_duplicate=True, action=replace
    ├─ rename    → 生成 {base}_copy{N}{ext} 避让文件名
    └─ quality   → compare_quality → replace 或 keep_existing
```

### 标题匹配

`is_title_match(title_a, title_b)` → `normalize_title` 去除 `.` `_` `-` `空格` `中文标点` 后小写比较

### 质量比较策略

`compare_quality(new_file_path, existing_file_path, new_file_info)`

```
1. 比较分辨率优先级分数
   ├─ new > existing → "replace"
   └─ new < existing → "keep_existing"
2. 分辨率相同时比较文件大小
   ├─ new > existing → "replace"
   └─ new ≤ existing → "keep_existing"
```

### 分辨率优先级

| 分辨率 | 分数 |
|--------|------|
| 4320p | 6 |
| 2160p | 5 |
| 1440p | 4 |
| 1080p | 3 |
| 720p | 2 |
| 480p | 1 |
| 360p | 0 |

### 策略结果对照

| 策略 | is_duplicate | action | 额外字段 |
|------|-------------|--------|---------|
| skip | True | skip | skip_message |
| replace | True | replace | skip_message |
| rename | True | rename | suggested_filename, skip_message |
| quality | True | quality | quality_decision, quality_reason, skip_message |
| 无重复 | False | 原策略 | - |

## 分类匹配器

**模块函数**（无类）

### 职责

根据刮削维度数据匹配路径规则，渲染入库目标路径。

### classify 流程

```
classify(scraped_info, path_rules)
│
├─ 第一轮：遍历 path_rules，match_conditions 命中 → render_template
├─ 第二轮：遍历 path_rules，conditions == {} 的兜底规则 → render_template
└─ 无匹配 → 返回空字符串
```

### 条件匹配

`match_conditions(dimensions, conditions)`

| 条件键 | 匹配方式 |
|--------|---------|
| 普通键 | `_to_comparable` 转换后严格相等 |
| `restricted_level` | 支持 `\|` 分隔的多值 contains 匹配 |
| None vs None | 视为匹配 |
| None vs 非None | 不匹配 |

### 模板渲染

`render_template(template, scraped_info, extra_vars)`

**变量来源优先级**: `extra_vars` > `scraped_info`

**特殊变量路径**: `{dimension.xxx}` → `scraped_info['dimensions']['xxx']`

**格式化语法**: `{key:format}` → Python format spec（如 `{season:02d}`）

**自动处理**:

| 场景 | 处理 |
|------|------|
| season/episode 无格式符 | 自动补零 `{int(value):02d}` |
| title_cn 为空但 title_en 有值 | title_cn 回退到 title_en |
| 变量值为 None | 替换为空字符串 |
| 空括号 `()` | 移除 |
| 连续 `/` | 合并为单个 |
| 尾部 `/` | 保留一个 |

## 安全工具

**模块**: `media_importer/core/safety.py`

> 回收站相关函数已拆分至 `core/recycle/` 子包，详见 [回收站管理](回收站管理.md)。本模块仅保留路径校验和安全操作功能。

### 允许的文件扩展名

| 类型 | 扩展名 |
|------|--------|
| 视频 | `.mkv` `.mp4` `.avi` `.ts` `.mov` `.wmv` `.m2ts` `.flv` |
| 字幕 | `.srt` `.ass` `.ssa` `.vtt` `.sub` |
| 合集 | `ALLOWED_MEDIA_EXTS = ALLOWED_VIDEO_EXTS \| ALLOWED_SUBTITLE_EXTS` |

### 函数清单

| 函数 | 用途 | 安全检查 |
|------|------|---------|
| `validate_path_safety` | 路径安全校验 | 目录穿越检测 + 白名单目录校验 |
| `validate_file_ext` | 文件扩展名校验 | 仅允许 ALLOWED_MEDIA_EXTS |
| `safe_delete` | 安全删除文件 | 路径校验 + 拒绝删目录 + 拒绝非普通文件 + 50GB 上限 |
| `safe_move` | 安全移动文件 | 源/目标路径校验 + 目标存在检测 + 跨设备回退(copy+delete) |
| `check_write_permission` | 写入权限检测 | 创建+删除测试文件 `.write_test` |
| `check_read_permission` | 读取权限检测 | 目录:listdir / 文件:read(1) |
| `make_fingerprint` | 计算文件指纹 | size+mtime SHA256 前16位 |

### validate_path_safety 规则

```
1. os.path.realpath 解析符号链接
2. 路径或真实路径含 ".." → 拒绝
3. allowed_base_dirs 非空时 → 真实路径必须以某个白名单目录为前缀
```

### safe_delete 保护机制

| 检查 | 限制 |
|------|------|
| 路径穿越 | 含 `..` 拒绝 |
| 目录 | 拒绝删除 |
| 非普通文件 | 拒绝删除（符号链接等） |
| 文件大小 | > 50GB 拒绝 |
| 权限 | PermissionError 返回失败 |

### safe_move 跨设备回退

```
os.rename(src, dest)
│
├─ 成功 → 返回
└─ OSError（跨设备）
    ├─ shutil.copy2(src, dest)
    ├─ os.remove(src)
    └─ 返回 "已复制+删除"
```

```
     └─────────────────────────────────┘
```

## 源目录清理器

源目录清理器是独立于任务流的文件操作功能，负责自动清理源目录中不属于任何任务关联的垃圾文件。

### 配置

| 键 | 类型 | 默认值 | 说明 |
|----|------|--------|------|
| `source_cleaner.enabled` | bool | false | 是否启用 |
| `source_cleaner.cleanup_mode` | string | "media_only" | media_only（仅保留影视+字幕）/ media_and_related（保留影视+字幕+关联文件） |
| `source_cleaner.ai_enabled` | bool | false | 是否启用 AI 辅助判断 |
| `source_cleaner.merge_strategy` | string | "intersection" | AI与规则合并策略：intersection（交集，保守）/ union（并集，激进） |
| `source_cleaner.junk_video_max_size_mb` | int | 50 | 垃圾视频大小阈值（0=不检测） |
| `source_cleaner.delete_extensions` | list | [".url", ".log", ".txt"] | 指定后缀名直接删除 |
| `source_cleaner.protect_extensions` | list | [".nfo", ".jpg", ".png"] | 指定后缀名保护不删 |
| `source_cleaner.blacklist_patterns` | list | ["RARBG*", "*/Sample/*", "*/sample/*"] | 文件名/路径黑名单 |
| `source_cleaner.cleanup_empty_dirs` | bool | true | 清理空目录 |
| `source_cleaner.confirm_before_cleanup` | bool | true | 清理前需用户确认 |
| `source_cleaner.schedule` | string | "0 3 * * *" | 定时触发（cron 格式） |

> **后缀名统一**：清理器不再硬编码视频/字幕后缀，改为从全局 `video_extensions`/`subtitle_extensions` 配置读取。`delete_extensions` 指定额外删除的后缀，`protect_extensions` 指定额外保护的后缀（优先级最高）。

### 清理模式

| 模式 | 保留 | 删除 |
|------|------|------|
| `media_only` | 视频+字幕 + protect列表 | 其余全部（非媒体文件） |
| `media_and_related` | 视频+字幕 + 同名关联文件 + protect列表 | 仅 delete列表 + 黑名单匹配 + 垃圾视频 |

同名关联文件匹配规则（`media_and_related` 模式）：与视频文件同目录且同基名（或基名前缀匹配）的非媒体文件视为关联文件。如 `电影.mkv` → `电影.nfo`、`电影-fanart.jpg`。

### AI 分析层

AI 不是规则的补充，而是对整体的独立分析层，以**目录**为单位分析：

```
扫描源目录全部文件
    ├── 规则引擎分析 → rule_items: {path: "keep"|"delete", reason}
    └── AI 整体分析 → ai_items: {path: "keep"|"delete", reason}
            │
            ▼
    合并策略（用户选择）
    ├── 交集模式（默认保守）：两者都判删才删
    └── 并集模式（激进）：任一判删即删
```

AI 提示词内置默认（`AI_SYSTEM_PROMPT`），可通过 `ai_prompt` 配置项自定义。AI 调用使用 `fast_model`（如配置）降低成本，`llm.api_key` 为空时 AI 分析静默跳过。

### 清理判定逻辑

```
源目录文件
    │
    ├─ 已关联任务（任务表中有记录）→ 保留
    │
    ├─ 黑名单目录匹配 → 整目录标记删除（move_dir_to_recycle）
    │
    ├─ 视频文件
    │   ├─ 后缀名匹配 protect_extensions → 保留
    │   ├─ 文件大小 < junk_video_max_size_mb → 垃圾视频，移入回收站
    │   └─ 文件大小 ≥ junk_video_max_size_mb → 保留
    │
    ├─ 字幕文件 → 保留
    │
    ├─ 非媒体文件
    │   ├─ 后缀名匹配 protect_extensions → 保留
    │   ├─ 路径/文件名匹配 blacklist_patterns → 移入回收站
    │   ├─ 后缀名匹配 delete_extensions → 移入回收站
    │   ├─ AI 辅助判断（如启用）→ AI 决定保留/清理
    │   └─ 按 cleanup_mode 默认行为
    │       ├─ media_only → 移入回收站
    │       └─ media_and_related → 保留（同名关联文件）
    │
    └─ 空目录 → move_dir_to_recycle（cleanup_empty_dirs=true 时）
```

### 与任务流的区别

| 维度 | 任务流源文件清理 | 源目录清理器 |
|------|----------------|-------------|
| 触发方式 | 任务完成时自动 | 定时触发（cron）或手动 |
| 清理范围 | 仅清理任务关联的源文件 | 清理源目录中所有非关联文件 |
| 配置键 | `source_policy.cleanup_source_after_done` | `source_cleaner.*` |
| 判定依据 | 任务状态 | 文件类型/规则/AI |
| 确认机制 | 无（自动执行） | confirm_before_cleanup 可选 |
| 回收站分区 | [源目录] | [清理器-源目录] |

## 职责边界

### 负责

- 源目录扫描与文件分组（FileScanner）
- 文件复制到中转目录，断点续传（FileCopier）
- 文件搬运到入库目录，应用文件名模板（FileMover）
- 入库去重检测与策略执行（DedupChecker）
- 维度→路径规则匹配（Classifier）
- 视频文件物理属性分析（FileAnalyzer）
- 安全工具：路径校验、文件移动、安全删除（Safety）
- 源目录自动清理（SourceCleaner）

### 不负责

- 回收站管理：浏览/恢复/永久删除/过期清理（由 [回收站管理](回收站管理.md) 模块执行）
- 任务状态管理（由 TaskManager 执行）
- 刮削逻辑（由 scraper 模块执行）
- 流水线编排（由 pipeline 模块执行）
- 通知发送（由 notify 模块执行）
- 配置管理（由 config_loader 执行）

### FileScanner 配置

|----|------|--------|------|
| `scan_source` | bool | True | 是否扫描源目录 |

| `video_extensions` | list | 内置列表 | 自定义视频扩展名 |
