# 文件处理端到端测试用例

> 版本：v1.0
> 日期：2026-05-30
> 测试类型：联合测试 + 回归测试
> 测试方式：真实 API 调用（TMDB + LLM）

---

## 一、业务流程总览

```
源目录扫描 → 文件复制 → AI刮削 → 验证 → 分类 → 去重 → 重命名 → 入库 → 通知 → 记录
    │            │         │        │       │       │       │        │
    │            │         │        │       │       │       │        └─ 清理模式
    │            │         │        │       │       │       └─ 模板渲染
    │            │         │        │       │       └─ 4种策略
    │            │         │        │       └─ 规则匹配/兜底
    │            │         │        └─ 4级置信度
    │            │         └─ Provider+AI / 纯AI
    │            └─ IO成功/失败
    └─ 源端去重: SKIP/RENAME/UPDATE_MTIME/REPROCESS
```

### 各环节分支因子

| 环节 | 因子 | 可选值 |
|------|------|--------|
| ①扫描-源端去重 | dedup_action | SKIP, RENAME_DETECTED, UPDATE_MTIME, REPROCESS |
| ②复制 | copy_result | 成功, IO失败 |
| ③刮削 | scrape_path | Provider+AI, 纯AI |
| ③刮削 | scrape_result | 成功(有结果), 失败(API异常) |
| ④验证 | confidence_level | PASS, CONFIRMING, NEEDS_REVIEW, FAILED |
| ④验证 | missing_field | 无, 缺标题, 缺类型, 缺年份, 年份异常 |
| ④验证 | data_gate | 通过, 阻断(来源不信任) |
| ⑤分类 | classify_result | 匹配规则, 兜底目录, 无匹配(失败) |
| ⑥去重 | dedup_result | 非重复, 重复-skip, 重复-rename, 重复-replace, 重复-quality保留, 重复-quality替换 |
| ⑦重命名 | media_type | movie, tv |
| ⑧入库-清理 | cleanup_source_after_done | true, false |
| ⑧入库-回收站 | has_recycle_dir | 有, 无 |
| ⑧入库-字幕 | has_subtitle | 有字幕, 无字幕 |
| 后置-确认 | confirm_result | 确认成功, 确认失败 |
| 后置-重分类 | reclassify_result | 重分类成功, 重分类跳过, 重分类失败 |
| 后置-重试 | retry_result | 重试成功, 重试失败 |
| 后置-忽略 | ignore_location | source, temp, recycle |

## 附录C：状态流转图（4业务状态模型）

```
待处理(PENDING) ──→ 处理中(PROCESSING) ──→ 完成(SUCCESS)
     │                    │
     │                    ├──→ 处理中(CONFIRMING) ──→ 完成(SUCCESS) (confirm_task)
     │                    │         │
     │                    │         └──→ 失败(FAILED) (confirm失败)
     │                    │
     │                    ├──→ 完成(SKIPPED) (去重跳过/用户忽略)
     │                    │
     │                    └──→ 失败(FAILED) ──→ 待处理(PENDING) (retry_task)
     │
     └──→ 完成(SKIPPED) (源端去重SKIP)
```
