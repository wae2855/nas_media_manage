1. 通过 WireGuard 等工具组建内网，或直接将 Hermes 部署在 NAS 服务器上

置信度计算配置

⚖
决策阈值 根据最终置信度自动判定任务状态 ▼
参数配置键说明默认值当前值
自动通过 自动通过 pass_threshold ≥ 此值自动通过，无需人工干预 0.8
需确认 需确认 confirm_threshold ≥ 此值需人工确认后入库 0.5
需审核 需审核 review_threshold ≥ 此值需审核，低于此值直接失败 0.3
🔍
搜索置信度 搜索准确度(search_conf) = T × R，评估 Provider 搜索结果的准确度 ▼
T — 标题匹配分
匹配级别配置键说明默认值当前值
TMDB 最低匹配阈值 tmdb_match_threshold T 低于此值不采用 TMDB 结果，触发 AI 清洗回退 0.85
L1 精确+年份精确 title_exact_with_year 标题完全匹配且年份一致 1.0
L2 精确+有季号 title_exact_with_season 标题精确匹配且含季号信息（剧集无年份时适用） 0.9
L3 精确无年份 title_exact_no_year 标题精确但无法确认年份 0.7
L4 精确年份不匹配 title_exact_year_mismatch 标题精确但年份不一致 常调 0.4
L5 模糊+年份一致 — 标题模糊匹配但年份一致，T=相似度值（无需额外系数） — T = best_sim
L6 模糊年份系数 title_fuzzy_year_coeff 模糊匹配且无年份或年份不匹配时的衰减系数，T=相似度×系数 常调 0.7
L7 最低相似度 title_min_similarity 低于此值判为无匹配 0.3
R — 搜索结果数惩罚 （以下为基础公式，最终 R 会根据 T 值动态调整）
inverse
R_base = 1/N
N=1→1.0, N=5→0.2
log
R_base = 1/log₂(N+1)
N=1→1.0, N=5→0.39
sqrt
R_base = 1/√N
N=1→1.0, N=5→0.45
flat
R_base = 1.0
任何 N → 1.0
参数配置键说明默认值当前值
结果数上限 R_max_results_cap N 超过此值不再增加惩罚 10
R 下限 R_min_value R 的最低值，防止惩罚过度 0.1
R 动态调节下限 R_T_floor T值超过此值时，R开始动态提升。T值越高匹配越可信，R惩罚应降低 0.5
R 动态调节曲线 R_T_curve 调节陡度，越大则高T值时R提升越快。1.0=线性，1.5=适中，2.0=激进 1.5
🤖
纯AI模式参数 TMDB 搜索无结果，或 T < 阈值且 AI Fallback 后仍不够时，纯 AI 刮削的置信度上限 ▼
参数配置键说明默认值当前值
高相似度上限 ai_cap_high_similarity AI 标题与文件名高相似度时的置信度上限 0.7
低相似度上限 ai_cap_low_similarity AI 标题与文件名低相似度时的置信度上限 0.3
AI 无标题上限 ai_cap_no_title LLM 未返回标题时的置信度上限 0.3
AI 无匹配上限 ai_cap_no_match 完全无匹配时的置信度上限 0.2
低相似度衰减系数 ai_cap_low_coeff 低相似度时的衰减系数 0.5
🎯
维度来源信任 为每个维度配置信任的数据来源，不在信任列表中的来源将触发人工审核 ▼
当前配置下的计算公式
Provider 优先模式（T ≥ 0.85 时）
search_conf = T × R_dynamic
R_dynamic = R_base × (1 - α) + α，其中 α = ((T - R_T_floor) / (1 - R_T_floor)) ^ R_T_curve
T 值越高 → α 越大 → R 越接近 1.0 → 结果数惩罚越轻
数据门控(data_gate) = 全部可信 ? 1.0 : 0.0
最终置信度(final) = search_conf × data_gate
search_conf = T × R（标题匹配分 × 结果稀缺性）
纯 AI 模式（T < 0.85 且 AI Fallback 无效时）
final = objective_cap × data_gate（纯AI模式）
门控拦截: 任一维度来源不在 trusted_sources → data_gate=0 → 强制需审核(NEEDS_REVIEW)
判定: 最终置信度 ≥ 0.8 → 自动通过   ≥ 0.5 → 需确认   ≥ 0.3 → 需审核   < 0.3 → 失败
