## 用户需要提供的截图

官方只要求截图来自真实应用界面并展示核心流程，没有在当前发布文档中规定固定张数或分辨率。建议最终安装候选版本后提供以下 4–5 张，截图前隐藏私人路径、账号和 API Key：

1. 首页：服务正常、版本号和产品用途。
2. 存储检查：来源、片库、回收目录的可用状态；路径可打码但状态应保留。
3. 任务工作台：电影和电视剧任务，季集使用“第 N 季 / 第 N 集”，不要再出现 `season` / `episode`。
4. 人工调整位置：原位置、目标片库/相对子目录及确认前预览。
5. 调整完成：原任务仍为已完成，新增“人工调整”历史任务；如官方需要移动端材料，再补一张手机窄屏。
