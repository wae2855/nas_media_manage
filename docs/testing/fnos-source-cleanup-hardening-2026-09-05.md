## 安全与范围

所有文件测试使用开发机临时样本与 SQLite，不读取/修改 fnOS 影视文件。常规清理无新增片库内容扫描；仅存在历史重复待清理时校验对应文件包。来源变化、缺证明、影片/字幕不匹配、活动任务或明确保留时均保留文件。不将旧 SKIPPED/FAILED 记录伪装成 SUCCESS。

归位并发锁适用于当前单进程多线程 HTTP 服务，不声称支持多进程写入。真机所见两条北海鲸梦历史记录的来源单元ID尚未读取，不能提前承诺它们一定满足自动覆盖条件；若不满足，新提示会指出阻挡文件和原因。
