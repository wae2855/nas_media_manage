# 配置开始页四步流程海报计划

在“开始”页上半区把产品从发现来源文件到安全入库的全过程做成四幕时间线，让第一次使用的用户先理解产品做什么，再进入具体配置。

## Target End State

- “不必从零配置”仍是主标题，右侧动态配置检查状态继续保留。
- 主视觉内清晰展示四步：获取电影文件、刮削电影资料、分拣归类、写入片库并处理来源文件。
- 最后一步只描述“按用户选择保留或依清理策略处理”，不暗示绕过回收与安全边界直接删除。
- 桌面端是横向电影分镜式时间线，移动端转为易读的竖向流程。

## Scope

- 修改开始页开场区 HTML 和现有 `cinema-config.css`。
- 增加静态结构测试，并同步需求看板和前端测试覆盖表。
- 用运行中的真实页面验证桌面端、移动端和控制台。

## Non-Goals

- 不修改胶卷导航、配置阶段或业务执行逻辑。
- 不增加点击、跳转或新的配置项。
- 不把流程描述做成另一组表单卡片。

## Subjective Contract

- **目标感受**：像 PPT 宣传页或电影分镜海报，用户扫一眼就能复述产品如何工作。
- **视觉节奏**：大号 01–04、金色轨道、短标题和一行解释；标题优先于说明。
- **反目标**：不做密集说明墙，不用四个同权重的普通设置卡，不遮挡动态检查状态。
- **移动端**：改为竖向时间线，字号和点击区域不靠缩小硬塞。

## Representative Preview

```text
01 获取电影文件  ━━━  02 刮削电影资料  ━━━  03 分拣归类  ━━━  04 写入与来源处理
   发现电影及同组文件       获取片名海报等资料        判断应进入哪个片库         写入后按选择保留或处理来源
```
