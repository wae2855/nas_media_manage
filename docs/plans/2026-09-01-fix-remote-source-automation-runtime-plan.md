# 网盘来源后台自动整理真实运行状态

- **Requirement**: [REQ-20260901-001019-2](../tracking/requirements-board.md)
- **ADR**: [0012 存储角色拓扑与目录边界](../decisions/0012-storage-role-topology.md)
- **Status**: pending_acceptance

## 目标

修复 fnOS 真机中“后台自动整理已开启，但 watcher 未运行”的问题。已授权、身份稳定、当前在线且可读写的已识别网盘来源应按 ADR-0012 允许自动扫描；挂载失效、身份变化、权限不足、空间不足或任何本地必需目录异常时仍须暂停并失败关闭。

## 非目标

- 不允许 `unknown` 来源自动扫描。
- 不允许回收、日志或缓存使用远程目录；中心中转角色已删除。
- 不放宽目标片库通用删除、覆盖或改名边界。
- 不改变用户已选择的来源永久删除策略及其既有隔离、快照和挂载复核协议。

## 实施任务

- [x] 以位置能力而非“存在任意黄色警告”计算自动运行许可；已识别远程来源允许自动扫描，其他风险保持阻断。
- [x] 配置检查同时核对自动运行许可与 watcher 真实状态，消除“检查通过但后台未运行”。
- [x] watcher 状态 API 返回配置意图、运行状态及明确阻断原因；前端不再用“全部绿色”笼统提示。
- [x] 修复配置前端载荷中的遗留敏感字段脱敏，禁止密钥或令牌明文返回。
- [x] 增加远程来源在线、挂载失效、未知来源、本地必需目录、配置检查和前端状态专项测试。
- [x] 同步监控、配置、存储安全与测试文档，完成定向测试、架构护栏、lint、编译和文档检查。

### 真机复验补充（版本事实与可见性）

- [x] 建立根目录单一版本事实源，构建参数与版本文件不一致时失败关闭。
- [x] 包内携带同一版本文件，FPK 校验器核对 manifest 与运行时版本完全一致。
- [x] 健康接口返回运行时真实版本；右上角状态胶囊下以低强调文字常驻展示，移动端无横向溢出。
- [x] 生成高于 fnOS 当前 `0.3.19` 的 `0.3.20` FPK，并记录独立校验结果。

### 扫描周期默认值补充

- [x] 将新安装及缺省配置的扫描周期统一为 300 秒（5 分钟），保留已有用户显式保存的周期和全部手动预设。
- [x] 补齐配置、前端、运行时和 fnOS 安装模板测试，递增版本并重新生成可验证安装包。

## 验收标准

1. 已授权 `fuse.rclone` 来源在线、身份未变化且其余目录满足要求时，保存后台自动整理成功，watcher 状态为 `running`。
2. 网盘来源掉线、不可读或挂载身份改变时，当轮扫描立即暂停且不把离线当空目录；恢复后重新核对文件。
3. `unknown` 来源以及远程回收/日志/缓存仍不得自动运行。
4. 配置检查不得在 `automatic_allowed=false` 或用户要求开启但 watcher 未运行时报告自动运行 PASS。
5. 前端明确区分“设置已保存”和“后台正在运行”，错误提示包含具体目录与原因。
6. 配置 API 不返回任何明文 API Key、secret、token 或 password。
7. 目标片库能力继续固定为 `delete=false`，相关安全测试通过。
8. 根 `VERSION`、manifest、包内 `server/VERSION`、健康接口和页面展示均为当前发布版本（本轮 `0.3.21`）；低版本或错配构建必须失败。
