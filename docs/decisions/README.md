# Architecture Decision Records

ADR 用来记录重要架构决策：为什么这样做、替代方案是什么、后续约束是什么。

## Template

```markdown
# ADR-0000: Title

Date:
Status: Accepted | Superseded | Deprecated

## Context

## Decision

## Consequences

## Alternatives

## Links
```
