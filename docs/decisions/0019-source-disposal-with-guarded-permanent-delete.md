# ADR-0019: 来源处置支持受控永久删除

Date: 2026-09-01
Status: Accepted
Requirement: REQ-20260901-020743
Amended by: ADR-0022（删除中心中转角色；来源处置安全合同保持有效）

## Context

ADR-0014 将来源处理收敛为保留全部、保留媒体并清理垃圾、入库后整组回收三种模式，所有被清理内容都进入本地回收区。这对本地下载最安全，但来源是云盘挂载时，会在“云盘 → 片库”之后再发生一次“云盘 → 本地回收”的跨盘复制，延长任务并额外占用本地空间。

产品需要让明确承担不可恢复风险的用户选择不再复制来源内容，同时保持目标片库现有文件的最高安全边界。

## Decision

1. 保留 `source_policy.mode` 的三态语义，新增从属字段 `source_policy.disposal_mode`：
   - `local_recycle`：默认，把规则确认的垃圾或已完成来源单元移入本地回收区；
   - `permanent_delete`：永久删除同一范围的来源内容，不创建本地回收副本。
2. `disposal_mode` 只在 `preserve_media` 和 `recycle_source_unit` 下生效；`preserve_all` 永远零写入来源目录。旧配置和缺失字段一律迁移为 `local_recycle`。
3. 配置界面在“入库成功后，来源内容怎么处理？”内展示互斥二选一。切换到永久删除时必须展示当前来源路径、不可恢复说明和独立确认；服务端只接受带本次危险确认的模式切换。普通保存提示不能代替危险确认。
4. 永久删除只允许作用于来源根内、已由来源清理器明确选中的垃圾，或 ADR-0014 定义且全部任务成功的来源单元。它不得作用于目标片库、日志、缓存或本地回收目录。
5. 目标片库重复项仍按 ADR-0018 逐项确认。用户选择替换时，片库旧文件必须进入本地回收区；回收不可用时停止，禁止因来源配置为永久删除而降级。
6. 整组来源单元的永久删除发生在作品身份、目标片库、最终路径、冲突决策、视频与全部字幕文件包提交、目标校验、任务状态落库之后。保留片库现有文件、跳过、失败、待确认或部分入库均保留来源。`preserve_media` 的明确垃圾只允许由智能清理入口执行，执行时必须排除所有任务已登记的来源/入库成员，并重新通过来源挂载、拓扑和路径边界检查。
7. 删除前重新验证来源挂载身份、允许根、来源单元代际快照、任务集合、普通文件/目录类型、未完成标记及活跃写入。任意深度出现符号链接、特殊文件、快照变化、无法读取成员或挂载变化时失败关闭，来源保持不变。
8. 永久删除不得直接递归作用于原始业务路径。执行器先在同一来源根内以独占名称建立任务删除隔离区，把快照内成员通过同盘重命名认领为 `.nas-media-delete-<unit-id>.deleting`，持久化删除账本后，只删除该任务已认领且身份匹配的隔离区。根散文件单元逐个认领，来源根本身永远不移动。
9. 隔离认领前失败必须零删除；认领后中断由删除账本恢复，只继续处理已认领隔离区，不扫描或猜测其他隐藏目录。永久删除无法提供事务级恢复，失败时必须把“已删除/待继续/未触及”成员和处理建议写入任务事件，不得谎报已全部清空。
10. 永久删除失败不得回退到本地回收，也不得重新从云盘复制；用户可修复权限后重试删除账本。来源永久删除和片库替换回收使用不同事件、账本类型和界面文案。
11. 本地文件系统的隔离区和成员继续使用 `st_dev + st_ino` 强身份复核。明确识别为 rclone/FUSE/NFS/SMB 等远程挂载时，不假设虚拟 inode 在 rename 后稳定；改用来源挂载身份、任务账本、隔离区边界、相对文件树、成员类型、大小和 mtime 复核。旧账本仅在当前来源仍能明确识别为远程挂载且所有边界吻合时采用该模式，未知挂载失败关闭。
12. 远程挂载不支持可靠 dir-fd 操作时，只允许在已验证的当前任务隔离区内逐层复核后按完整路径删除。恢复结果只要不是成功就必须立即停止并保留原始错误，禁止继续检查已被认领的旧路径而覆盖故障原因。

## Consequences

- 云盘来源可避免成功入库后的第二次跨盘复制和本地回收空间占用。
- 配置与任务详情需要明确区分“可恢复回收”和“不可恢复删除”，并展示实际来源单元边界。
- 需要任务所有权删除隔离区、持久化账本、崩溃恢复和部分删除事实；实现与测试成本明显高于直接调用递归删除。
- 同盘重命名依赖挂载能力；挂载不支持安全认领时永久删除必须失败关闭，不能改为逐路径直接删除。
- 这是 ADR-0014 和通用影视文件回收红线的窄例外，不扩大到目标片库或其他目录角色。

## Alternatives

- 永远复制到本地回收：最安全，但云盘会重复传输并占用本地空间，不能满足已确认场景。
- 直接对来源路径调用 `unlink/rmtree`：缺少任务所有权、崩溃恢复和路径替身防护，否决。
- 回收失败时自动永久删除：把环境故障变成不可恢复数据操作，否决。
- 依赖云盘厂商回收站：不同挂载协议和供应商语义不一致，不能作为产品保证，否决。
