# ADR-0018: 目标片库只新增与冲突逐项确认

Date: 2026-08-31
Status: Accepted
Requirement: REQ-20260831-004019

## Context

目标片库保存用户长期维护的影片。旧重复策略允许后台根据配置或质量比较自动处置现有文件，且检测动作早于新文件成功发布。多片库后，这种隐式写操作会放大数据安全与理解成本。

## Decision

1. 目标片库默认只新增；重复检测是只读操作，不得移动、覆盖或删除文件。
2. 同作品候选和最终目标同名均进入 `PENDING/AWAIT_REVIEW`，冲突事实结构化保存。
3. 未决冲突只能由用户逐项选择保留现有、保留两份或替换现有；普通确认和批量确认不得绕过。
4. 替换前必须重检目标路径与 SHA-256 内容哈希，旧文件必须进入已验证的本地回收区；禁止永久删除降级。
5. 多片库冲突操作限定在本任务实际目标根，其他根最多提供只读提示。
6. 旧自动重复策略只作读取兼容，运行时和再次保存后统一采用人工确认。
7. 新文件长复制完成后必须再次复核旧文件内容；旧文件使用唯一临时路径认领，最终发布只能在目标仍不存在时成功。并发写入、符号链接或临时记录冲突均失败关闭。

## Consequences

- 后台自动整理遇到重复时会停在任务列表，吞吐量让位于数据安全和明确授权。
- 用户能看到两份文件并自主选择，误识别不会自动影响片库。
- 替换流程需要指纹 CAS、回收账本和失败恢复测试。
- 原配置中的质量优先、自动替换不再产生自动文件写操作。

## Alternatives

- 根据分辨率/大小自动保留高质量版本：指标不等于用户偏好，否决。
- 只对完全同名文件确认，语义同作品继续自动处理：行为不一致，否决。
- 跨片库根统一去重：可能处置用户未选中的硬盘，否决。
