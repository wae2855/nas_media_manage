# Feature Documentation

Feature docs are the current source of truth for business capabilities.

Each feature document should answer:

- What business capability does this feature own?
- Which code entrypoints implement it?
- Which configuration keys and DB tables are involved?
- Which API routes and frontend views depend on it?
- Which tests verify it?
- Which files are current, pending migration, or archived?
