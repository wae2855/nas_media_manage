安全提醒

本程序如需与 Hermes 服务通信，为保障 NAS 数据安全，建议采取以下措施：
1. 通过 WireGuard 等工具组建内网，或直接将 Hermes 部署在 NAS 服务器上
2. 在配置文件中设置 server.api_key 启用 API 认证
3. 避免将 API 端口直接暴露到公网，防止未授权访问导致数据损失

轮询监控配置

启用后自动监控源目录，发现新文件时触发入库处理
每隔多少秒检查一次源目录，建议30-120秒

API 安全配置

设置后所有 API 请求需携带认证头，留空则不启用认证。建议使用随机字符串，如: openssl rand -hex 32
⚠️ 修改端口影响面较大，需同步处理以下事项：
1. 重启服务后生效，浏览器登录地址需同步修改
2. Hermes 的 Skill 路由配置中 NAS API 地址需同步修改，否则 Hermes 无法回调
3. 若通过 FNM OS 应用商店安装，需同步修改应用端口配置
4. 防火墙规则需放行新端口

📖 提示词编写指南

文件结构

提示词采用双文件管理：

  • scraper_prompts.example.md：出厂默认模板（只读，不会被程序修改）
  • scraper_prompts.md：您的自定义文件（保存时自动创建，优先使用）
  • 点击"重置为默认"会删除自定义文件，恢复使用出厂模板
提示词结构

提示词分为上下两半：

  • 上半部（下方编辑区）：您自由编写的内容，会完整发送给 AI
  • 下半部（程序自动追加）：分隔线 + 维度列表 + JSON Schema，无需手动编写
限制级分类（必须包含）

请在提示词中明确说明限制级判断标准，程序会自动补充可选值：

restricted_level 分级标准（4选1）：
- "0-6": 适合0-6岁幼儿/儿童
- "7-12": 适合7-12岁儿童/家庭
- "13-15": 适合13-15岁青少年
- "17+": 仅适合17岁以上成人
动漫分类（必须包含）

请在提示词中明确说明动漫判断标准：

animation 判断标准（true/false）：
- true: 任何动画形式
- false: 真人拍摄的作品
其他维度
  • media_type：movie（电影）/ tv（电视剧）
  • documentary：true（纪录片）/ false（不是纪录片）
刮削优化建议
  • 提供具体例子（如"小猪佩奇→0-6"）帮助 AI 理解
  • 强调标题翻译规则，使用官方译名而非直译
  • 说明 confidence 评分的含义和评分标准
  • 保留原有的重要规则（如幼儿动画、低龄启蒙→0-6）
