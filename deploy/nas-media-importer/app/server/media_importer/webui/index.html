安全提醒

本程序如需与 Hermes 服务通信，为保障 NAS 数据安全，建议采取以下措施：
1. 通过 WireGuard 等工具组建内网，或直接将 Hermes 部署在 NAS 服务器上
2. 在配置文件中设置 server.api_key 启用 API 认证
3. 避免将 API 端口直接暴露到公网，防止未授权访问导致数据损失

API 安全配置

设置后所有 API 请求认证需要密码，留空则不启用认证,可以理解它是不需要用户名的密码。
⚠️ 修改端口影响面较大，需同步处理以下事项：
1. 重启服务后生效，浏览器登录地址需同步修改
2. Hermes 的 Skill 路由配置中 NAS API 地址需同步修改，否则 Hermes 无法回调
3. 若通过 FNM OS 应用商店安装，需同步修改应用端口配置
4. 防火墙规则需放行新端口

基础配置

待整理的媒体文件源目录。如果使用 /vol1/、/vol2/ 等共享盘下的目录， 必须在 fnOS 应用中心 → nas-media-importer → 设置 → 授权目录 中添加并赋予【读】权限。
注意：如果源目录是飞牛挂载的网盘目录，文件刷新时间可能较久，建议改用Alist网盘来实现短时刷新。
启用后将递归扫描源目录下的子目录，发现更深层的媒体文件
源目录递归扫描的最大深度，建议 3-5 层
用于暂存正在处理的媒体文件，建议预留至少 100GB 空间（一部高码率电影可能就需几十 GB）。
考虑读写速度，建议目录创建在固态硬盘上以加快处理。
⚠️ 中转目录不能与源目录或隔离区目录相同，否则会导致数据丢失！
源目录清理策略

源目录中的文件处理完成后会自动清理（包括视频和附属字幕文件），以保持源目录干净。具体规则：

  • 处理成功 → 源文件立即删除
  • 处理跳过 → 源文件移入隔离区
  • 处理失败 → 源文件移入隔离区
  • 需人工确认 → 文件暂存中转目录，人工确认后继续处理
去重扫描策略

扫描源目录时，会检查同一文件路径是否存在历史任务：

  • 有正在处理或待确认的任务 → 跳过，不重复创建
  • 历史任务已结束（成功/失败/跳过） → 重新创建，当作新文件处理
扫描源目录时会对文件进行重复校验，已在处理或待确认的文件不会重复创建任务。
处理失败的文件将被移动到此目录，需确保路径存在且应用有读写权限。
注意：隔离区文件不会被自动删除，请定期检查和清理。
⚠️ 隔离区不能与源目录或中转目录相同，否则会导致数据丢失！

TMDb 元数据 API

优先使用 TMDb (The Movie Database) 刮削，失败时降级到 LLM
获取地址：themoviedb.org/settings/api
低于此阈值 TMDB 结果将被拒绝，降级到 LLM 直接刮削
TMDB 置信度计算规则

置信度 = 信息完整度 × 结果分散系数

级别触发条件完整度分
L1英文名、中文名、年份都与 TMDB 一致1.0
L2英文名 + 年份与 TMDB 一致1.0
L3英文名一致，无年份0.7
L4英文名一致，年份不同0.4
L5英文名模糊匹配 + 年份一致相似度
L6英文名模糊匹配，无年份相似度 × 0.7

结果分散系数 = 1 ÷ 搜索结果数

结果数12345…
系数1.00.50.330.250.2…

举例：Interstellar 2014 → 唯一命中 → 1.0 × 1.0 = 1.0

A Wrinkle in Time 2018 → N=2 同名 → 1.0 × 0.5 = 0.5

2024.1080p.mkv → 无英文名、无年份、N 很大 → <0.1 直接拒绝

提示词结构

提示词分为上下两半：

  • 上半部（编辑区）：通用规范，如角色定义、数据源优先级、标题翻译规则等

维度判断规则

由维度配置中的 AI 提示词定义，运行时自动拼接。

  • 在「映射标签设置」中编辑维度 AI 提示词
  • 启用/禁用维度自动影响拼接内容
  • 点击「预览完整提示词」查看实际发送内容
两种提示词区别
  • LLM 直接刮削：无 TMDb 数据，AI 从文件名推理
  • LLM+TMDB 刮削：有 TMDb 数据，AI 整理校验
