## 修复：Thumbnail 文件夹为空时轮盘不应显示图片

**问题**：用户发现当资源目录的 Thumbnail 文件夹没有图片时，首页轮盘区域仍有图片在滚动。

**根本原因**：`loadReelWheelFromTasks()` 函数在缩略图 API 返回空时，会回退到使用任务列表的封面色填充轮盘。

**修复方案**：
1. 修改 `media_importer/webui/js/cinema-app.js` 中的 `loadReelWheelFromTasks()` 函数
   - 删除回退到任务封面色逻辑（原 741-751 行）
   - 当缩略图为空时，直接传入空数组 `[]` 给 `buildReelWheel()`
   - `buildReelWheel([])` 会隐藏轮盘并显示空状态

2. 修复 `media_importer/api/thumbnail_handlers.py` 中的拼写错误
   - 第 78 行：`mimetypes.guess_type` 拼写错误修正

**验证**：
- 后端 API `/api/thumbnails` 正确返回空列表
- 前端接收到空列表后正确显示空状态

**用户操作要求**：需要清除浏览器缓存并硬性重新加载页面（Ctrl+Shift+R 或 Cmd+Shift+R）
